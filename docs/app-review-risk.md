# App Review 与服务条款风险清单

> 本文件不是法律意见。上架/分发/公开测试前，发布方需自行核对最新版 [App Store Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)、米哈游服务条款、品牌/内容授权与当地法律。

## 2. 关键条款说明（需按最新原文核对）

### 2.1 App Review 2.5.4（后台模式）

Apple 要求 App 使用后台模式时必须有明确、正当、与用户可见功能一致的理由。对 CloudFloat：

- 唯一后台模式是 `audio`；
- 只在真实媒体播放或 PiP 可见时配置 `AVAudioSession .playback`；
- 不播放静音音频、不做位置/VoIP/截图保活；
- 如果真机验证表明 PiP/音频不能成立，发布构建应移除 `audio` 后台模式或默认关闭音频，而不是换一种后台模式。
- 审核备注应包含：真实媒体路径、操作步骤、PiP/音频预期、如何停止、为何不使用其他后台模式。
- 详见 [background-audio.md](background-audio.md)。

### 2.2 4.2 Minimum Functionality

纯 WKWebView 套壳可能被认定为功能过薄。CloudFloat 的差异化能力：

- 媒体/PiP 能力探测与逐项原因反馈（不是简单打开网页）；
- 三层会话状态与服务器会话 UNVERIFIED 的诚实展示；
- 诊断导出、脱敏、恢复策略（无自动重复计费）；
- 离线测试页与开发者工具（Debug）。
- 审核材料应演示这些能力，而不是只展示官方网页。

### 2.3 5.2.1 品牌/内容授权

- App 名称/图标/界面不使用米哈游或《云·星穹铁道》官方 Logo/商标冒充官方客户端；
- 应用内展示的官方页面标题/Logo 属于网页内容，不是 App 自有品牌；
- 元数据、截图、宣传不得暗示官方合作/授权，除非有书面授权；
- 发布前取得品牌/内容使用授权或法律意见；准备下架/停止分发预案。

### 2.4 4.7 流媒体游戏/迷你 App

Apple 对云游戏/流媒体/迷你 App 有额外规则（内容分级、目录、审核、支付等）。CloudFloat 不内置游戏目录或支付，仅作为官方网页浏览器，但仍可能被审核归入相关类别。发布前：

- 按最新版 4.7 核对适用性；
- 准备内容/年龄分级说明；
- 确认是否需要额外审核材料；
- 不与“绕过 App 内购买”的方案结合。

### 2.5 5.1 隐私

- App 本体不收集账号密码/token；官方网页数据由米哈游处理；
- 诊断仅内存、脱敏、用户主动导出；
- 无分析/广告/追踪 SDK；
- `PrivacyInfo.xcprivacy` 仅声明 UserDefaults（CA92.1）；
- 发布方需提供隐私政策 URL，说明官方网页的第三方数据处理；
- 若未来加入崩溃/分析 SDK 或云同步，必须更新隐私标签/清单并重新评估。

### 2.6 3.1 支付（如适用）

如果官方页面提供云游戏时长/订阅/内购，用户在 WebView 内完成支付可能触发 Apple 的 App 内购买/外部购买规则。CloudFloat 不接入自建支付、不代收费用；发布前需与审核/法务确认该浏览器场景的适用性。

## 3. 米哈游服务条款风险

需要发布方核对（以官方最新条款为准）：

- 是否允许通过第三方浏览器/WebView 访问云游戏；
- 是否允许自动化、脚本、挂机、后台运行；
- 账号共享/设备限制/反作弊；
- 对页面注入脚本（即使只读探测）的容忍度；
- 商业使用/品牌/内容授权。

当前实现不注入业务操作、不自动点击、不绕过空闲超时；但媒体探测脚本会读取 DOM/媒体事件并添加可选 PiP 按钮。若条款不允许任何注入，应停止分发并移除探测注入，仅保留普通浏览器。

## 4. 发布前检查清单

- [ ] 真机 T02/T03/T05 与 30 分钟 ×3 完成，证据脱敏且可复核；
- [ ] App Store 元数据、截图、预览不出现“后台挂机/自动战斗持续”等未验证表述；
- [ ] 品牌/内容授权或法律意见完成；
- [ ] 隐私政策 URL、支持 URL、审核联系人/测试账号（如需）准备；
- [ ] 审核备注解释后台音频/PiP/登录流程与停止方式；
- [ ] 确认无私有 API、无静音音频、无位置/VoIP/截图保活；
- [ ] 确认 Release 构建不暴露测试页实验室/本地服务器；
- [ ] 确认 `PrivacyInfo.xcprivacy` 与实际 API/数据一致；
- [ ] 确认出口合规信息；
- [ ] 年龄分级与网页内容一致；
- [ ] 准备若审核拒绝后台音频的降级构建（移除 `audio` 后台模式/关闭音频）；
- [ ] 准备若官方页面拒绝 WKWebView 的停止分发/限制说明。

## 5. 结论

CloudFloat 的合规策略是“少声明、可验证、可降级”：

- 不宣称未验证的 PiP/后台挂机；
- 不用私有 API/伪后台；
- 只保留真实媒体所需的后台音频；
- 所有诊断/导出默认脱敏、用户主动；
- 真机证据缺失时，宁可标记 UNVERIFIED，也不伪造成功。

这些措施降低但不消除审核/条款风险；最终发布决策与法律责任由发布方承担。
