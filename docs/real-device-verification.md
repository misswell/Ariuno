## 2. 环境与过程

1. 使用 Xcode 27.2 + Apple Development 身份构建并安装到 iPhone 15 Pro。
2. 官方入口在 App 的 WKWebView 中显示登录面板；用户自行完成登录（助手未接触凭证）。
3. 用户进入云游戏，页面显示游戏画面；修正了“媒体已就绪但加载遮罩仍不消失”的 UI bug 后重新安装。
4. 重装后官方登录状态仍保留，直接显示“进入游戏”，无需重新登录。
5. 本地视频 PiP 测试完成后，切到官方游戏，使用游戏自带自动战斗并进入 PiP。

## 7.5 关键失败结论（T04/T05）

- 失败现象：游戏网页自身显示**“连接中断 / 因为您长时间未操作游戏，已中断连接 / 错误码：-1022”**；PiP 浮窗结束。
- 这是云游戏服务器的空闲策略，不是 App 的 WebView 崩溃或页面刷新；Ariuno 没有也不应通过自动点击、伪造输入或私有 API 绕过。
- 因此：
  - **T03**：单次游戏实时 PiP 可判 PASS（浮窗非截图、战斗画面更新），但不等于会话可持续；
  - **T04**：**FAIL**（15 分钟空闲断线，未到 30 分钟）；
  - **T05**：**FAIL**（1 次战斗推进后会话断开；无 3 次持续证据）。
- 不得宣传“后台挂机成功”；只能交付浏览器 + 诊断原型，并在 [known-limitations.md](known-limitations.md) 说明失败原因。
