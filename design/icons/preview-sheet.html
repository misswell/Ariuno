CloudFloat · App Icon

六款图标方向

全部按 iOS 图标规范绘制：1024 × 1024 满版、无圆角、无透明通道，系统会自动裁成圆角矩形。主色延续 AccentColor（#327AFA），图形围绕“云游戏 + 画中画 + 漂浮”三个关键词。

现行图标双窗轮廓 · 紫蓝渐变
01
双窗悬浮
FLOATING PIP

大窗轮廓里浮出一块白色小窗，最直白地表达“画中画”。延续现行图标的构图，但改成实心小窗 + 投影，层级更干净。

02
云端开玩
CLOUD PLAY

云朵里挖出一个播放键，一秒说清“在云上玩游戏”。造型最亲和，小尺寸识别度也最高，适合走轻松、消费级路线。

03
蓝白极简
MINIMAL BLUE

浅色底 + 粗蓝描边，把画中画收进屏幕内部。最克制、最像系统级工具，白底和深色壁纸上都立得住。

04
深空播放
DEEP PLAY

深海军蓝背景 + 玻璃屏 + 白色播放键，靠光晕营造夜间、沉浸的气质。适合和深色模式 UI 成套。

05
浮空屏
FLOATING SCREEN

主屏微微倾斜、小窗脱开悬浮，强调名字里的“Float”。动态感最强，也最容易被记住。

06
云上浮窗
CLOUD WINDOW

播放窗悬浮在云朵上方，把“云”和“画中画”两件事同时收进画面，品牌语义最完整。

选择建议

  • 要稳 → 01 双窗悬浮：延续现行图标，老用户一眼认得出，画中画语义最直白。
  • 要快 → 02 云端开玩：小尺寸最清楚，适合主推“云游戏”这件事。
  • 要记住 → 05 浮空屏：倾斜的主屏 + 脱开的小窗，最有“Float”的动感。
  • 注意 → 03 是浅底，在纯白壁纸上会略淡；04 是深底，在纯黑壁纸上边界偏弱。
